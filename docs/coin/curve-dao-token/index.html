📖 Curve DAO nedir?

Similar to Uniswap, Curve Finance is an Automated Market Maker (AMM) based Decentralised Exchange (DEX). Unlike Uniswap, its main focus is only to swap between assets that are supposed to have the same value. This is useful in the DeFi ecosystem as there are plenty of wrapped tokens and synthetic tokens that aim to mimic the price of the real underlying asset.&nbsp; For example, one of the biggest pools is 3CRV, which is a stablecoin pool consisting of DAI, USDT, and USDC.…
